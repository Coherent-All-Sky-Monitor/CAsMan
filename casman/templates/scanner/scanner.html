Scanner Guide

Main Action Buttons & Workflows

Row 1 - Connection Management

Connect Parts - Create a new connection between two parts sequentially

  1. Select Action → Choose Connect Parts
  2. Choose Input Method → Barcode Reader or Manual Entry
  3. Enter First Part → Scan or build part number
  4. Enter Second Part → Scan or build part number
  5. Review Connection → Verify parts and connection order
  6. Confirm → Execute connection
  7. View Result → Success message with option to connect more parts

Remove Part - Disconnect ALL connections to/from a part (destructive operation)

  1. Select Action → Choose Remove Part
  2. Choose Input Method → Barcode Reader or Manual Entry
  3. Enter Part to Remove → Scan or build part number
  4. Review All Connections → See list of all connections that will be deleted
  5. Confirm Removal → Execute removal of ALL connections
  6. View Result → Success message with option to remove another part

Replace Part - Swap one part for another while maintaining ALL its connections

  1. Select Action → Choose Replace Part
  2. Choose Input Method → Barcode Reader or Manual Entry
  3. Enter Old Part → Scan or build part number of part to be replaced
  4. View Connections → System displays ALL incoming and outgoing connections
  5. Enter New Part → Scan or build part number of replacement (must be same type/polarization)
  6. If replacing BACKBOARD: Choose to keep same SNAP port OR select new SNAP port (chassis/slot/port)
  7. Review Replacement → See old part, new part, ALL connections to transfer, and SNAP choice (if applicable)
  8. Confirm Replacement → Execute: disconnect old part from ALL connections, connect new part to ALL connections (with new SNAP if selected)
  9. View Result → Success/failure summary for each connection transferred

Disconnect Parts - Remove a single connection between two specific parts

  1. Select Action → Choose Disconnect Parts
  2. Choose Input Method → Barcode Reader or Manual Entry
  3. Enter First Part → Scan or build part number
  4. Enter Second Part → Scan or build part number
  5. Review Connection → Verify the specific connection to remove
  6. Confirm Disconnection → Execute disconnection
  7. View Result → Success message

Row 2 - Information & Notes

Insert Part Notes - Add append-only notes to a part with timestamp

  1. Select Action → Choose Insert Part Notes
  2. Choose Input Method → Barcode Reader or Manual Entry
  3. Enter Part Number → Scan or build part number
  4. Enter Note Text → Type your note in the text area
  5. Submit Note → Save note with automatic timestamp
  6. View Result → Success message with option to add more notes

Part History - View complete connection history and all notes for a part

  1. Select Action → Choose Part History
  2. Choose Input Method → Type Part Number or Build Part Number
  3. Enter Part Number → Type complete number OR select type/properties
  4. View History → See chronological table of connections/disconnections and all notes
  5. Return to Menu → Back to main menu

Row 3 - Position Assignment

Assign Antenna Position - Assign grid position (chassis/slot/port/direction) to antenna

  1. Select Action → Choose Assign Antenna Position
  2. Choose Input Method → Barcode Reader or Manual Entry
  3. Enter Antenna Part → Scan or build antenna part number
  4. Select Chassis → Choose chassis number (1-4)
  5. Select Slot → Choose slot letter (A-K)
  6. Select Port → Choose port number (0-11)
  7. Select Direction → Choose direction (North/Center/South)
  8. Confirm Position → Execute position assignment
  9. View Result → Success message with option to assign another position

Navigation: Back, Cancel, and Reset buttons are available at each step to help you navigate the workflow.
